# Hello World (TypeScript)

A minimal "Hello World" example written in TypeScript.

## Requirements

- Node.js 18+
- npm

## Installation

```bash
npm install
```

## Running

Build and run:

```bash
npm run dev
```

Or build once, then run separately:

```bash
npm run build
npm start
```

## Project structure

```
.
├── src/
│   └── index.ts    # entry point, prints "Hello, World!"
├── tsconfig.json   # TypeScript compiler configuration (strict mode)
├── package.json
└── Readme.md
```
